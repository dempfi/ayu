# Version 6.2.1
- Linter and plugin highlights draw in clear ayu hues again, with tinted fills that keep text readable
- The Install button in the A File Icon prompt works with Package Control 4
- Tab close buttons light up on hover with default settings
- Autocomplete no longer fills the console with `background_color` errors
- ayu runs on Sublime's modern plugin host

# Version 6.2.0
- Colors follow the current ayu palette, shared with ayu for VS Code. Light changes the most
- ayu's own file icons, the same set as VS Code, now cover 142 file types through A File Icon
- Separators between panels are shown by default. Set `"ui_separator": false` to hide them
- The command palette input blends into the palette instead of standing out
- Zig storage types are colored as types
